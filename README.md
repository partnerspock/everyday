# Everyday - Multi-Purpose Workspace & Productivity App

> **Everyday** is a robust, modular productivity and management web application designed to help you organize notes, projects, spaces, sub-notes, and reminders all in one place. Built with flexibility in mind, it features a complete admin role & permission management system, activity logging, and a clean, user-friendly interface. 🌟

Feel free to use it, study it, or contribute to making it even better! 🎉

---

## Key Features

* 🔐 **Advanced Admin & Role Management**: Comprehensive role-based access control (RBAC) with customizable permissions and admin registration.
* 🗂️ **Spaces & General Notes**: Organize your workflow into dedicated spaces and manage secure or general notes (including unlock features).
* 📋 **Projects & Sub-Projects**: Track projects, sub-projects, file attachments, and their current statuses seamlessly.
* ⏰ **Reminders & Sub-Notes**: Keep track of daily tasks, sub-tasks, and timely reminders.
* 📜 **Activity Logs**: Monitor system activities and administrative actions in real-time.
* 🌱 **Database Seeder Ready**: Comes pre-packed with robust database seeders and dummy data so you can test all features right out of the box!
* 🎨 **Clean & Responsive Interface**: Optimized for smooth navigation across different devices.

## Prerequisites

Before running this project locally, ensure you have the following tools installed on your computer:
* [PHP](https://www.php.net/) (Latest version recommended)
* [Composer](https://getcomposer.org/)
* [MySQL](https://www.mysql.com/) or MariaDB
* [Node.js & NPM](https://nodejs.org/) (For compiling assets)
